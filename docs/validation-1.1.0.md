## 复现与验收

1. 配置本机外部 MSST、DDSP 和混音依赖，先检查 `cover_doctor`。
2. 创建全新输出目录，从有权使用的原始录音裁同一时间段，保留幅度和浮点格式。
3. 调用 README 中四个工具，保存每次返回值、阶段 manifest 和转换 provenance。
4. 核对二次分离输入仅包含一级 vocals；换声 key、实际模型与选择窗口一致；混音采用原伴奏及原 karaoke 残差，时长对齐。
5. 检查 `cover_verify.technicalChecksPassed`，再单独进行等响试听。技术通过不是听感批准。

不得用先前文件满足本次输出。已有目标会被拒绝，重试应使用新的目录。不要把含私人绝对路径的 manifest 或用户音频提交到仓库。
